# 搬瓦工套餐怎么选：线路、机房与购买指南

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 品牌。它提供不同配置、线路和机房的虚拟服务器，并使用 KiwiVM 控制面板管理服务。对于想学习 Linux、部署个人网站，或需要为不同地区访问者选择服务器的人来说，选购时不仅要看价格，还要弄清楚资源、流量和机房之间的关系。

下面的搬瓦工套餐对比以参考资料所列方案为基础，帮助你从需求出发缩小选择范围。价格和配置不是实时库存或报价，购买时应以对应产品页面和结算信息为准。

## 从需求出发，而不是先挑最低价

先写下服务器准备做什么，以及主要访问者在哪里。学习 Linux 或试运行个人项目，可以先关注基础配置和总预算；网站面向国内访问者时，除了资源，还要考虑访问者使用的运营商与套餐所含线路；若业务需要香港或日本机房，就应直接核对对应地区是否在产品的可选范围内。对服务可用性有明确要求的业务，还需要单独审阅 SLA 条款，而不能仅凭套餐名称判断保障范围。

资源方面，CPU、内存和存储影响可用的计算与空间余量，月流量则关系到数据传输额度。配置表中的带宽和月流量是不同指标：前者描述连接速率规格，后者是一个月的传输额度。选择时要同时考虑应用本身、访问量和预计传输量；同样是 1GB 内存的方案，也可能有不同的 CPU、硬盘和流量，不宜只看单一数字。

付款周期同样会改变预算安排。年付方案需要一次支付更长周期的费用；季付或月付则应按各自报价计算总支出。先确定可接受的周期，再比较同一方案的价格，比直接比较不同周期的标价更有意义。对不确定长期需求的读者，也应先了解续费金额及适用条件。

## 看懂线路和机房

线路名称和机房地点解决的是不同问题：地点说明服务器所在位置，线路则涉及网络如何连接。选择搬瓦工机房时，不能把某个地区或线路名称当成所有用户都适用的速度结论；访问者所在地、运营商和具体套餐的可选机房都值得一起考虑。

参考资料提到的主要线路包括：

- **CN2 GT**：电信 CN2 线路的一种，资料称回程走 CN2，去程可能经过普通骨干网。KVM 套餐的部分机房使用这一线路。
- **CN2 GIA**：电信 CN2 线路，资料将它与 CN2 GT 的区别描述为去程、回程均走 CN2。洛杉矶 DC6、DC9 以及表中的香港、大阪方案涉及此线路。
- **CMIN2 和 CUP**：分别是中国移动精品骨干网和联通精品网的名称。参考资料称 DC6、DC9 接入了 CMIN2 和 CUP，因此查看 GIA-E 方案时，也应关注自己所在网络及所选机房。
- **大阪软银**：是参考资料列出的日本大阪机房线路之一。它与大阪 CN2 GIA 是不同的线路描述，不应仅因为地点同在大阪就视为同一方案。

套餐的机房切换范围并不相同。KVM 的可选地点包括洛杉矶部分机房、弗里蒙特、新泽西、纽约和阿姆斯特丹；GIA-E 资料列有 DC6、DC9、温哥华、大阪软银和荷兰 EUNL_9 等；香港方案则列有香港、新加坡、东京和大阪等 CN2 GIA 机房。具体可选项应在产品页面及面板中核对，不要将一个套餐的地点清单套用到另一个套餐。

切换前还要看规则，而不仅是目的地。参考资料特别指出，KVM 套餐切换至洛杉矶 DC3 后，流量变为原来的三分之一。若月流量对项目重要，切换前应先确认目标机房对应的额度及面板提示，再决定是否迁移。

### 入门预算与 GIA-E 的取舍

KVM 入门套餐适合以学习或小型项目为出发点、希望控制预算的人。它的年付报价低于表中其他列出年付价格的常规方案，但机房和线路范围与 GIA-E 不同。参考资料还提到 KVM 20G 年付可能缺货，并列出 $27.99/季度起的季付方案；是否有货以及季付方案的具体配置，应在购买时确认。

如果关注国内访问所涉及的线路，可以进一步比较 CN2 GIA-E 标准和大流量款。两者均列有 DC6、DC9 等多个机房，但大流量款从 1 核、20GB SSD、1TB 月流量提高到 2 核、40GB SSD、2TB 月流量，内存仍为 1GB。是否值得增加预算，取决于所需流量、存储和 CPU，而不是只看“大流量”名称。

### 亚太机房与 SLA 需求

大阪和香港方案适合明确需要相应地区机房的读者。大阪方案与香港标准款的表列配置同为 2 核、1GB 内存和 40GB SSD，但月流量和价格不同；香港大流量款增加到 2GB 内存和 1TB 月流量。比较时应将地域、流量额度和周期费用放在一起看，而不是只按距离或标称带宽判断。

对于需要服务保障的业务，资料中的 CN2 GIA SLA 方案列有 99.99% 在线时间 SLA，并对应 DC5 SLA 机房。这个数字需要结合实际合同理解：购买前应查看适用范围、计算方式及服务条款，也要确认报价和配置是否符合业务要求。SLA 与普通套餐的取舍涉及服务条件，不能只比较硬件规格。

## 购买与使用：按顺序核对

1. **确定用途和预算。** 列出所需资源、主要访问地区和可接受的付款周期，再从表中挑选一个或几个方案。若尚未确定用量，尤其要留意月流量与机房切换规则。
2. **进入对应产品页面。** 使用表中与方案名称一致的链接，核对 CPU、内存、存储、带宽、流量和可选机房。不同产品即使名称相近，也不能假定配置或切换范围完全相同。
3. **检查库存与结算信息。** 确认可购买的周期、价格及订单总金额；如有优惠码，确认结算页面是否接受以及折扣适用条件。缺货时不要把历史报价视为当前可购买的保证。
4. **选择付款方式。** 参考资料列出支付宝和银联；实际可用选项以结算页面显示为准。付款前再检查方案和周期，避免只关注首期价格而忽略后续费用。
5. **在 KiwiVM 中管理服务器。** 资料列出的功能包括获取 SSH 信息、重装系统和切换机房。先查看面板提供的信息与提示，再按自己的用途操作；重装或迁移前，应确认相关操作对现有数据及流量规则的影响。

如果还没有决定具体方案，可以先[查看所有在售套餐](https://bwh81.net/aff.php?aff=85071&gid=1)，再返回对照配置和可选地点。列表中显示的方案和库存可能随时间变化。
